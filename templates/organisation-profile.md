# Organisation profile

**Template — fill in an approved local system. No organisation facts or approval are implied.**

| Field | Local value and evidence/reference |
| --- | --- |
| Profile ID, owner, date and version | To be completed. |
| Selected runbook(s) | Employee / customer / both; confirm remit. |
| Next decision and priority activity | What must someone be able to achieve, and what decision is needed now? |
| Organisation/entities, sector and jurisdictions | Confirm employee/customer locations, service context and cross-border dependencies. |
| In-scope audiences and lifecycle | Include relevant candidates, contractors, service users and intermediaries. |
| Services, tools, suppliers and channels | Inventory what is known; link to owners, configurations, integrations, legacy assets and renewal/change plans. |
| Adopted commitments, policy, contract and obligation routes | References with adoption/verification status. Separate proposed ambitions. |
| Existing evidence | Date, method, environment, coverage, limitations and secure reference. |
| Known barriers and consequences | Critical blocked activities, harm, cumulative burden and urgent support route. |
| Participation and missing voices | Accessible recruitment/contribution, influence, dissent and gaps. |
| Decision rights and existing governance | Actual owner/deputy, delegation and escalation route. |
| Delivery capacity and resources | Confirmed skills, protected time, specialist support, budget and proposals. |
| AI tools and data permissions | Approved purposes, environments, integration/access scope and execution limits. |
| Reporting and review | Audiences, normal planning cycles, event triggers and locally agreed cadence. |
| Secure record location | Approved location, access, retention and disclosure controls. |
